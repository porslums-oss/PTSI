Smart ER — คู่มือการใช้งาน (ฉบับผู้ใช้)

สำหรับพยาบาล เวชระเบียน แพทย์ และผู้ดูแลระบบ — อธิบายตามงานที่ทำจริงในห้องฉุกเฉิน

เวอร์ชัน: 1.0ผู้อ่าน: ผู้ใช้งานทุกบทบาทอัปเดต: 2026-10-06ภาพหน้าจอจากระบบทดสอบ (ข้อมูลจำลอง)
i
ระบบนี้ใช้ทำอะไรผู้ใช้งาน
Smart ER ช่วยให้ห้องฉุกเฉินรู้ว่า ใครอยู่เตียงไหน รอใคร อยู่ขั้นตอนไหน — ลงทะเบียนด้วยการสแกนสายรัดข้อมือ, คัดกรอง ESI, จัดเตียง, เรียกคิว, ดูสัญญาณชีพจากเครื่อง monitor และแสดงสถานะบนจอ TV / Tablet ประจำเตียง

ข้อสำคัญ: ระบบเป็นเครื่องมือ แสดงผลและบริหารงาน ไม่ใช่ระบบตัดสินใจทางคลินิก — ระดับ ESI ต้องมาจากการประเมินของพยาบาลเสมอ

1

เข้าสู่ระบบทุกบทบาท

  1. เปิดเบราว์เซอร์ (Chrome / Edge) ไปที่ที่อยู่ระบบที่ รพ. แจ้ง
  2. ใส่ ชื่อผู้ใช้ และ รหัสผ่าน แล้วกด เข้าสู่ระบบ
  3. เมื่อเข้าแล้วมุมซ้ายล่างแสดงชื่อและบทบาทของคุณ
  4. ออกจากระบบทุกครั้งที่ไม่ได้ใช้เครื่อง (เมนู “ออกจากระบบ”) — session หมดอายุเองใน 12 ชั่วโมง
เมนูหลัก: สแกน / ลงทะเบียน · ผังเตียง · คิว / เรียกผู้ป่วย · HL7 Monitor / API · จอ TV · ตั้งค่าระบบ · ออกจากระบบ
2

สแกนและลงทะเบียนงานประจำของจุดรับผู้ป่วย

สแกนสายรัดข้อมือทำได้จากทุกหน้าจอ

  1. ยิงบาร์โค้ดที่สายรัด — ไม่ต้องคลิกช่องใดก่อน (ถ้ากำลังพิมพ์ในช่องอื่นอยู่ ระบบจะไม่ดักเพื่อไม่รบกวน)
  2. พบผู้ป่วย → แสดงข้อมูล, visit ปัจจุบัน, สัญญาณชีพ และปุ่มคัดกรอง / เปลี่ยนสถานะ / เข้าคิว / จำหน่าย
  3. ไม่พบ → ขึ้นฟอร์มลงทะเบียนพร้อม HN ที่สแกนมา
  4. ไม่มีเครื่องสแกน: พิมพ์ HN ในช่องค้นหาด้านบนแล้วกด ค้นหา

ลงทะเบียนผู้ป่วยใหม่เวชระเบียน / พยาบาล

  1. ที่เมนู สแกน / ลงทะเบียน กด + ลงทะเบียนผู้ป่วยใหม่ (หรือสแกน HN ที่ไม่มีในระบบ)
  2. กรอกอย่างน้อย ชื่อ; ข้อมูลอื่นกรอกเท่าที่มี — แพ้ยา/แพ้อาหารควรกรอกทุกครั้ง
  3. เลือกอาการสำคัญ ระดับ ESI (ถ้าประเมินแล้ว) และเตียง
  4. ติ๊ก เพิ่มเข้าคิว ถ้าต้องการเรียกคิวทันที
  5. กด ลงทะเบียน + พิมพ์สายรัด → พิมพ์สายรัดข้อมือ (บาร์โค้ดคือ HN) แล้วสวมให้ผู้ป่วย
HN ซ้ำ / เลขบัตรประชาชนซ้ำ จะถูกปฏิเสธ — ให้ค้นหาผู้ป่วยเดิมแทนการสร้างใหม่

ผู้ป่วยวิกฤตที่ไม่ทราบชื่อ (Crisis)ไม่ต้องรอเอกสาร

  1. ในฟอร์มลงทะเบียน ติ๊ก Crisis → ช่อง HN ถูกปิด
  2. ระบบออกเลข ER ชั่วคราว (เช่น ER00001) และเปิด visit ทันที
  3. เมื่อทราบตัวตนแล้ว: ตั้งค่าระบบ → รวมเลข ER ชั่วคราว → HN จริง ใส่เลขชั่วคราว + HN จริง แล้วกด รวม HN
หลังรวมแล้ว การสแกนเลข ER เดิมจะไปที่ HN จริงอัตโนมัติ และประวัติ visit ถูกรวมไว้ที่ HN จริง
3

คัดกรอง เตียง คิว จำหน่ายงานประจำของพยาบาล

คัดกรอง / ประเมิน ESI และเปลี่ยนสถานะพยาบาล / แพทย์

  1. เปิดผู้ป่วย → กด คัดกรอง / ESI เลือกระดับ 1–5 ใส่สัญญาณชีพและหมายเหตุ แล้วบันทึก — ประเมินซ้ำได้ทุกครั้งที่อาการเปลี่ยน (เก็บประวัติทุกครั้ง)
  2. กด เปลี่ยนสถานะ เลือกสถานะ เช่น รอแพทย์ตรวจ / กำลังตรวจ / รอผลเลือด / รอ Admit — ข้อความนี้คือสิ่งที่ญาติเห็นบนจอ TV
  3. กด บันทึกแพทย์ ใส่ชื่อแพทย์และ Diagnosis
ESIสีเป้าหมายรอพบแพทย์
1แดงทันที (0 นาที)
2ชมพูภายใน 10 นาที
3เหลืองภายใน 30 นาที
4เขียวภายใน 240 นาที
5ขาวภายใน 480 นาที

ผังเตียง และการจัดเตียง38 เตียง / 8 โซน

  1. เมนู ผังเตียง — ด้านบนมีตัวเลขสรุป (เตียงว่าง, ผู้ป่วยใน ER, คิวรอเรียก, เกินเวลาเป้าหมาย, Alarm 1 ชม.) รีเฟรชเองทุก 10 วินาที; สีของแต่ละเตียงคือระดับ ESI ของผู้ป่วย เตียงว่างเป็นสีเทา ป้าย HL7 = มีเครื่อง monitor ผูกกับเตียง
  2. ในหน้าผู้ป่วยกด ผูกเตียง เลือกเตียง — ระบบไม่ให้ 2 คนอยู่เตียงเดียวกัน
  3. ย้ายเตียง = เลือกเตียงใหม่ ประวัติการย้ายถูกเก็บไว้

คิว / เรียกผู้ป่วยพยาบาล

  1. เมนู คิว / เรียกผู้ป่วย — เรียงตาม ESI แล้วตามเวลามาถึง
  2. กด 📢 เรียก → จอ TV ขึ้นแถบ “ขอเชิญ HN ••• · เตียง …” (เรียกด้วยเลข + เตียง ไม่เรียกชื่อ)
  3. ไม่มาตอบ กด เรียกซ้ำ; ตรวจเสร็จกด ✓ เสร็จ
  4. ✕ ยกเลิก ต้องระบุเหตุผล (ผู้ป่วยไม่อยู่ / เรียกผิดคน / ผู้ป่วยปฏิเสธ / ส่งต่อไปจุดอื่น)

จำหน่าย / ส่งต่อพยาบาล / แพทย์

  1. เปิดผู้ป่วย → กด จำหน่าย / ส่งต่อ
  2. เลือกผล: กลับบ้าน · Admit · ICU · CCU · Cath lab · ส่งต่อ รพ.อื่น · ปฏิเสธการรักษา (AMA) · เสียชีวิต
  3. กด ยืนยันจำหน่าย → เตียงว่างและ Tablet ที่เตียงล็อกอัตโนมัติ
ตรวจก่อนยืนยัน: การจำหน่ายย้อนกลับไม่ได้จากหน้าจอ — ถ้ากดผิดให้แจ้งผู้ดูแลระบบ
4

สัญญาณชีพ (HL7)ข้อมูลจากเครื่อง Patient Monitor

HL7 Monitor — สัญญาณชีพพยาบาล / ADMIN

  1. เมนู HL7 Monitor / API → แท็บ สัญญาณชีพ Real-time แสดงค่าล่าสุด (HR, SpO₂, BP ฯลฯ) ต่อเตียง
  2. แท็บ เครื่อง Monitor ดูสถานะ ONLINE/OFFLINE (ADMIN ผูกเครื่องกับเตียงได้)
  3. แท็บ Alarm ดู alarm 24 ชั่วโมงล่าสุด กด รับทราบ เมื่อดำเนินการแล้ว
  4. แท็บ Message Log และ ทดสอบส่ง HL7 ใช้ตรวจปัญหาและทดสอบ (ทดสอบส่งได้เฉพาะ ADMIN / NURSE); แท็บ REST API เป็นเอกสารอ้างอิงสำหรับผู้ดูแลระบบ
5

จอ TV และ Tablet ประจำเตียง

จอ TV ในโถงรอญาติ / ผู้ป่วย

  1. จอแสดงสถานะผู้ป่วยแต่ละราย โดยปกปิด HN (แสดง 4 หลักท้าย) ไม่มีชื่อ และสลับหน้าอัตโนมัติ
  2. เมื่อเรียกคิว แถบ “ขอเชิญ” ปรากฏบนจอ
  3. ถ้าขึ้นแถบสีส้ม “ขาดการเชื่อมต่อกับระบบ” แปลว่าจอไม่ได้รับข้อมูลใหม่ — อย่าเชื่อข้อมูลบนจอ แจ้ง IT
  4. พยาบาล/ADMIN เปิดจอ TV ได้จากเมนู จอ TV (ระบบแนบรหัสเข้าถึงให้เอง)

Tablet ประจำเตียงพยาบาล / แพทย์ / ADMIN

  1. หน้าล็อก แสดงเฉพาะเลขเตียงและสี/สถานะ ไม่มีชื่อหรือ HN — ญาติเห็นได้ปลอดภัย
  2. กด เข้าสู่ระบบ ด้วยบัญชีของตนเอง (เฉพาะ NURSE / DOCTOR / ADMIN) → เห็นเฉพาะผู้ป่วยของเตียงนี้ พร้อมสัญญาณชีพ
  3. เปลี่ยนสถานะ และรับทราบ Alarm ของเตียงตัวเองได้
  4. ล็อกเองเมื่อไม่ใช้งาน 15 นาที, เมื่อผู้ป่วยออกจากเตียง/จำหน่าย กดออกจากระบบทุกครั้งเมื่อเสร็จ
6

งานผู้ดูแลระบบADMIN

งานของผู้ดูแลระบบ (ADMIN)เมนู “ตั้งค่าระบบ”

  1. ค่าตั้งค่า: ชื่อ รพ., การปกปิด HN บนจอ TV, รอบสลับหน้า, เวลาล็อก Tablet ฯลฯ — ทุกการแก้ไขถูกบันทึก audit
  2. Tablet ประจำเตียง: เพิ่ม tablet → ได้รหัสจับคู่ 8 ตัว (ใช้ครั้งเดียว หมดอายุ 10 นาที) → ไปเปิด /bed.html บน Tablet แล้วกรอกรหัส; ยกเลิกเครื่องที่หาย; ดูบันทึกการใช้งาน
  3. ผูกเครื่อง Monitor กับเตียง ที่เมนู HL7 Monitor
  4. รวมเลข ER ชั่วคราว เป็น HN จริง
