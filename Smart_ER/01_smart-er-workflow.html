Smart ER — Workflow ผู้ป่วยห้องฉุกเฉิน

Triage → ลงทะเบียน / HN → คัดกรอง ESI → แพทย์ตรวจ → Lab / X-ray → สังเกตอาการ → จำหน่าย / Admit / ส่งต่อ ICU · CCU · Cath lab

#ผู้ใช้บทบาทใน Smart ERหน้าจอที่ใช้สิทธิ์
1พยาบาลคัดกรอง (Triage)รับผู้ป่วย ประเมินเบื้องต้น แยก Crisis / Non-crisis ระบุระดับ ESIลงทะเบียน, ผังเตียงเขียน
2เจ้าหน้าที่เวชระเบียนออก / ค้นหา HN พิมพ์สายรัดข้อมือ รวมเลขชั่วคราวกับ HN จริงลงทะเบียน, สำเร็จเขียน
3พยาบาล ERจัดเตียง จัดคิว เรียกผู้ป่วย อัปเดตสถานะ (รอผลเลือด, รอ X-ray ฯลฯ)ผังเตียง, จัดการคิว, เรียกผู้ป่วยเขียน
4แพทย์ตรวจ สั่ง Lab / Med / X-ray ตัดสินใจ D/C · Admit · Referผังเตียง (อ่าน), EMRอ่าน + สั่งการ
5ผู้ดูแลระบบตั้งค่าธีม เสียงเรียก รอบสลับหน้าจอ จัดการผู้ใช้ตั้งค่าAdmin
6ผู้ป่วย / ญาติดูสถานะบนจอ TV ฟังเสียงเรียกจอติดตามสถานะดูอย่างเดียว

รายละเอียดแต่ละขั้นตอนInput · Action · Output

2.1 Triage — คัดแยก Crisis / Non-crisisจุดแรกที่ผู้ป่วยพบเจ้าหน้าที่

Triage Nurse
  • ประเมินสัญญาณชีพ / อาการนำ ตัดสินใจภายใน 1–2 นาที
  • Crisis (หมดสติ, หยุดหายใจ, ช็อก) → เข้าห้อง Resus ทันที ไม่ต้องรอลงทะเบียน
  • Non-crisis → ส่งไปจุดลงทะเบียน
arrival_timechief_complaintcrisis_flag

2.2 ลงทะเบียน / ออก HNคู่มือหัวข้อ 3–4

เวชระเบียน
  • ค้นหา HN เดิม หรือกด สร้าง HN สำหรับผู้ป่วยใหม่ กรอกชื่อ–นามสกุล
  • พิมพ์ สายรัดข้อมือ (Barcode HN, ชื่อ, วันที่) — ต้องตรวจสอบข้อมูลก่อนพิมพ์
  • ผู้ป่วย Crisis ได้ เลข ER ชั่วคราว ก่อน แล้วรวมกับ HN จริงภายหลัง (“HN รอบ 2” ในบันทึก)
hnfirst_namelast_nametemp_er_nomerged_to_hn

2.3 พยาบาลคัดกรอง — ระบุ ESI / สีเตียงคัดกรอง 1–3 ในบันทึก

พยาบาล
  • ประเมินระดับ ESI 1–5 → กำหนดสี (แดง / ชมพู / เหลือง / เขียว / ขาว)
  • บันทึก Diagnosis เบื้องต้น สัญญาณชีพ
  • สีนี้จะแสดงบนผังเตียงและจอ TV ทันที

2.4 จัดเตียง & เข้าคิวคู่มือหัวข้อ 2, 5, 7

Smart ER
  • เลือกเตียงว่างจากผังเตียง (R / N / NT / T / 20–21 / จุดคัดกรอง / VVIP / สังเกตอาการ 29–38)
  • เพิ่มผู้ป่วยเข้าคิว ด้วยการค้นหา HN → สถานะ รอเรียก
  • ลำดับคิวควรเรียงตาม ระดับ ESI ก่อน แล้วจึงเวลามาถึง
bed_codequeue_noqueue_statuspriority

2.5 เรียกผู้ป่วยคู่มือหัวข้อ 6

Smart ER
  • กด เรียก → ระบบประกาศเสียง (Google TTS / Browser TTS) และแสดงบนจอ
  • ปุ่ม เรียกซ้ำ · เสร็จ · ยกเลิก — บันทึกเวลาเรียกทุกครั้ง
called_atrecall_countcalled_by

2.6 แพทย์ตรวจ & สั่งการตามบันทึก: Doctor → LAB / Med / X-Ray

แพทย์
  • ตรวจร่างกาย สั่ง LAB / ยา / X-ray / CT / MRI
  • พยาบาลเปลี่ยนสถานะเป็น รอผลเลือด, รอผลเลือดและ X-ray, รอ X-ray / CT / MRI — ญาติเห็นบนจอ
doctor_idorder_laborder_xraystatus_code

2.7 สังเกตอาการ & บันทึก EMRเตียงสังเกตอาการ (4–6 ในบันทึก / 29–38 ในระบบ)

พยาบาล
  • ย้ายเตียงไปโซนสังเกตอาการ สถานะ สังเกตอาการหลังฉีดยา
  • ผลการรักษาทั้งหมดบันทึกเข้า EMR ของโรงพยาบาล

2.8 Disposition — จำหน่าย / Admit / ส่งต่อปลายทาง ICU · CCU · Cath lab

แพทย์
  • จำหน่ายกลับบ้าน, Admit หอผู้ป่วย, ส่ง ICU / CCU, ส่ง Cath lab, Refer
  • ระบบ คืนเตียงเป็นว่าง และนำผู้ป่วยออกจากจอ TV อัตโนมัติ
dispositiondischarge_timeer_length_of_stay
KPI ที่ได้ฟรีจากข้อมูลนี้: Door-to-Doctor time, ER Length of Stay, เวลารอแยกตามสี, สัดส่วน Admit — ใช้ทำรายงานคุณภาพ ER ได้ทันที

ระดับความเร่งด่วน (สี)ตามป้ายคัดแยกหน้าห้องฉุกเฉิน

ESIสีชื่อบนจอความหมายเวลาที่ต้องได้รับการตรวจ
1แดงImmediateคุกคามต่อชีวิต เช่น หยุดหายใจ ช็อก หมดสติทันที
2ชมพูEmergencyเสี่ยงอาการทรุดลง เช่น เจ็บหน้าอก แน่นหน้าอก ซึมลงภายใน 10 นาที
3เหลืองUrgencyอาการรุนแรงปานกลาง เช่น ปวดท้องสงสัยไส้ติ่งภายใน 30 นาที
4เขียวSemi-urgencyไม่รุนแรง เช่น ปวดท้อง ปวดศีรษะเล็กน้อย ไข้หวัดรอได้ 2–4 ชั่วโมง
5ขาวNon-urgencyไม่เร่งด่วนรอได้มากกว่า 4 ชั่วโมง
ข้อสังเกต: ระยะเวลาเป้าหมายข้างต้นอ่านจากป้ายในภาพถ่าย ต้องยืนยันกับเกณฑ์ที่โรงพยาบาลใช้จริง (MOPH ED Triage / ESI) ก่อนตั้งค่าเป็นเวลาแจ้งเตือนในระบบ

#หน้าจอขั้นตอนผู้ใช้ข้อเสนอเพิ่ม
1เข้าสู่ระบบ—ทุกคนล็อกเอาต์อัตโนมัติ, บัญชีรายบุคคล
2แสดงเตียงผู้ป่วย2.4, 2.7พยาบาล, แพทย์สีขอบเตียงตาม ESI, เวลาอยู่ในเตียง
3ลงทะเบียนผู้ป่วย2.2เวชระเบียนตรวจ HN ซ้ำ, เลข ER ชั่วคราว
4ลงทะเบียนสำเร็จ2.2เวชระเบียนพิมพ์สายรัดซ้ำ + log
5 / 7จัดการคิว2.4พยาบาลเรียงคิวตาม ESI อัตโนมัติ
6เรียกผู้ป่วย2.5พยาบาลบังคับเหตุผลเมื่อยกเลิก
8ตั้งค่าระบบ—Adminจำกัดเฉพาะ Admin
9ติดตามสถานะผู้ป่วยและญาติ2.3–2.8ญาติ (จอ TV)ปกปิด HN บางส่วน, แบ่งหน้าอัตโนมัติ
+(ใหม่) หน้าคัดกรอง ESI2.3พยาบาลยังไม่มีในคู่มือ — สีมาจากไหนต้องมีหน้าจอบันทึก

ประเด็นที่ต้องยืนยันจากบันทึกลายมือที่อ่านไม่ชัด

  • ข้อความ “Program … ยังไม่ได้เลือกใช้งาน” ใกล้ Crisis / Non-crisis — ยังไม่ได้เลือกระบบ HIS/โปรแกรมหลักใช่หรือไม่
  • รายการย่อย 3 ข้อใต้กล่อง “Smart ER” (มุมบนซ้าย) — ขอบเขตงาน / โมดูลที่ต้องการ
  • ตัวเลข “staff ≈ 1,000,000”, “Sog”, “110”, “mm — 5,000” — เป็นงบประมาณ (ค่าพัฒนา / ฮาร์ดแวร์ / MA) หรือไม่
  • “ESI – X”, “Dig – 13 …” — เกณฑ์ ESI หรือจำนวน Diagnosis ที่ต้องรองรับ
  • เตียงคัดกรอง 1–3 และสังเกตอาการ 4–6 ในบันทึก เทียบกับรหัสเตียงจริงในระบบ (R/N/NT/T/29–38)
  • “HN รอบ 2” — เป็นการรวมเลขชั่วคราวกับ HN จริง หรือเป็นการออก Visit ใหม่
  • เชื่อม HIS / LIS / PACS / EMR ตัวใด ผ่านวิธีไหน (API, DB link, HL7/FHIR)
