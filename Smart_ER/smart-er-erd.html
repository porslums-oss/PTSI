07

ข้อตกลงในการอ่านผัง

PK / FK / UK

Primary / Foreign / Unique key — ชนิดข้อมูลเต็ม (เช่น numeric(12,3)) และ default อยู่ในไฟล์ Excel

Partial unique index

visit(patient_id) WHERE discharge_at IS NULL = ผู้ป่วยมี visit เปิดได้ 1 · visit(bed_code) = เตียงละ 1 คน · bed_terminal(bed_code) WHERE active = เตียงละ 1 tablet

Logical reference (FK*)

ตาราง partition รายเดือน (hl7_message, vital_sign) และ log ไม่ใส่ FK เพื่อลดภาระ insert ทุกวินาที — ตรวจความถูกต้องใน function

HN / barcode

patient.hn unique · wristband.barcode_value = HN (Code 39) · เลขชั่วคราว ER00001 ใช้ merged_to_hn redirect

Token / รหัสผ่าน

รหัสผ่าน bcrypt · device token และรหัสจับคู่ tablet เก็บเป็น SHA-256 เท่านั้น

เวลา

ทุกคอลัมน์เวลาเป็น timestamptz · DB timezone = Asia/Bangkok · visit_no ใช้ปี พ.ศ. 2 หลัก
