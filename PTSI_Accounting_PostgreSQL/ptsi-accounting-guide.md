## System in one paragraph
Ported from Oracle APEX (WKSP_PTSI, app 151494) to PostgreSQL schema `acct` (Neon DB `ptsi_accounting`). Business logic lives in DB functions `acct.fn_*` (SECURITY DEFINER) and triggers; Node/Express `app/server.js` (~120 endpoints) only checks permissions (`requiredPerm()`), calls `fn_*`, and maps `RAISE EXCEPTION 'CODE: thai message'` to HTTP status via ERR_STATUS. The UI is one file `app/public/index.html` (vanilla JS, no build; API cache + prefetch + navSeq guard; generic clear-form buttons). Vercel serverless via `api/index.js` + `vercel.json`; Node >= 20; dependencies only express and pg. Optional AI import (Gemini or Anthropic) via env vars.

## Database facts
- 55 tables, 9 views, 87 functions, 28 triggers, 153 indexes, 48 sequences. Roles acct_owner / acct_app / acct_report; extensions pgcrypto, pg_trgm.
- Document numbers: Q-{cat}-NNNN; DN/INV/BN/RC/CN/PR/PO/GR/AP/PAY/VCN/WHT/CB/JV-YYYYMMDD-NNNNN (not guaranteed continuous - confirm with accountant for tax invoices).
- GL mapping keys: AR_CONTROL, AP_CONTROL, VAT_OUTPUT, VAT_INPUT, WHT_RECEIVABLE, WHT_PAYABLE, DEFAULT_CASH, DEFAULT_REVENUE, DEFAULT_EXPENSE, SHARE_CAPITAL.
- Period close via trigger fn_period_guard (only ADMIN can reopen); audit via fn_audit_trigger.
- Roles ADMIN / ACCOUNTANT / SALES / VIEWER; permissions admin, sales.edit, purchasing.edit, cashbook.edit, gl.post, period.close, doc.void, master.edit (editable in Settings).
- Error codes worth knowing: PO_REQUIRED, ALREADY_POSTED, OVER_APPLIED, OVER_CREDIT, OVER_RECEIVE, OVERPAY, PERIOD_CLOSED, DUPLICATE, GL_MAPPING_MISSING, UNBALANCED_JOURNAL, FORBIDDEN.

## Correct DB install order (validated on a fresh DB)
neon_1_roles_schema.sql (edit the 3 role passwords first, >= 12 chars) -> neon_2_functions -> neon_3_views_seed -> data_migration 01..07 in order (05 needs 02/03 for FKs) -> neon_5 ... neon_21 in numeric order. neon_4_healthcheck.sql is read-only, run anytime; expect 55/9/87/28. Run with a superuser/owner (scripts use SET ROLE acct_owner). The old db/install_db.sh is outdated - do not use. Seed creates user `admin` with a known default password: change immediately.

## Deploy
- Cloud: Neon (pooled DATABASE_URL, role acct_app) + GitHub + Vercel (Framework Other). Env: DATABASE_URL, optional PG_POOL_MAX, AI_PROVIDER, GEMINI_API_KEY, GEMINI_MODEL, GEMINI_FALLBACK_MODEL, GEMINI_THINKING, ANTHROPIC_API_KEY, ANTHROPIC_MODEL. Never upload .env.
- On-prem: Node 20 + PostgreSQL 16, systemd unit, nginx TLS (raise client_max_body_size >= 5m), cron backup.sh with pg_dump, ~/.pgpass. Windows (NSSM/PM2/IIS) and macOS/Docker steps exist in doc 05 but are untested on real machines.
- Verify: /api/health, neon_4 counts, login + change admin password, create quote->invoice->receipt and check Trial Balance and 'unbalanced journals' = 0, role 403 checks.
